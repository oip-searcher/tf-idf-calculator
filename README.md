> папки tokens_per_doc и lemmas_per_doc, а также файл lemmas.txt.

## Описание

Приложение вычисляет TF-IDF для терминов и лемм по каждому документу на основе результатов предыдущих заданий.

Работа программы состоит из двух шагов:

1) Сбор статистики DF для всех документов

- Для каждого документа читается список терминов из папки `tokens_per_doc/`.

- Для каждого термина определяется, в скольких документах он встречается.

- Для каждого документа читается список лемм из папки `lemmas_per_doc/`.

- Для каждой леммы определяется, в скольких документах она встречается.

- Дополнительно из файла `lemmas.txt` загружается соответствие вида: `термин -> лемма`.

2) Расчёт TF-IDF для каждого документа

- Для каждого документа извлекаются термины из текста страницы.

- Вычисляется TF каждого термина в документе.

- На основе ранее собранной статистики вычисляется IDF каждого термина.

- Рассчитывается значение TF-IDF для терминов.

- Затем термины группируются по леммам.

- Для каждой леммы рассчитываются TF, IDF и TF-IDF.

- Результаты сохраняются в отдельные файлы для терминов и лемм.

## Формулы:

Используются следующие формулы:

- `TF = count(term in document) / totalTermsInDocument`

- `IDF = log(N / (1 + df))`

- `TF-IDF = TF * IDF`

где:

- `N` — общее количество документов

- `df` — количество документов, в которых встречается термин или лемма

## Результат

После выполнения для каждого документа создаются два файла:

- `N_terms.txt` — TF-IDF для терминов документа в формате: `термин idf tfidf`
- `N_lemmas.txt` — TF-IDF для лемм документа в формате: `лемма idf tfidf`

Файлы сохраняются в папку:

- `tfidf_output/`
