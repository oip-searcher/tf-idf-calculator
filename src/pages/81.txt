		<div id="mw-content-text" class="mw-body-content"><div class="mw-content-ltr mw-parser-output" lang="ru" dir="ltr"><p><b>ASP.NET</b> (Active Server Pages для .NET)&#160;— платформа разработки <a href="/wiki/%D0%92%D0%B5%D0%B1-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5" title="Веб-приложение">веб-приложений</a>, в состав которой входят: <a href="/wiki/%D0%92%D0%B5%D0%B1-%D1%81%D0%B5%D1%80%D0%B2%D0%B8%D1%81" class="mw-redirect" title="Веб-сервис">веб-сервисы</a>, программная инфраструктура, модель программирования<sup id="cite&#95;ref-:0&#95;1-0" class="reference"><a href="#cite_note-:0-1"><span class="cite-bracket">&#91;</span>1<span class="cite-bracket">&#93;</span></a></sup>, от компании <a href="/wiki/%D0%9C%D0%B0%D0%B9%D0%BA%D1%80%D0%BE%D1%81%D0%BE%D1%84%D1%82" class="mw-redirect" title="Майкрософт">Майкрософт</a>. ASP.NET входит в состав платформы <b><a href="/wiki/Microsoft_.NET" class="mw-redirect" title="Microsoft .NET">.NET Framework</a></b><sup id="cite&#95;ref-2" class="reference"><a href="#cite_note-2"><span class="cite-bracket">&#91;</span>2<span class="cite-bracket">&#93;</span></a></sup> и является развитием более старой технологии <a href="/wiki/Active_Server_Pages" title="Active Server Pages">Microsoft ASP</a>.
</p><p>ASP.NET внешне во многом сохраняет схожесть с более старой технологией ASP, что позволяет разработчикам относительно легко перейти на ASP.NET. В то же время внутреннее устройство ASP.NET существенно отличается от ASP, поскольку она основана на платформе <a href="/wiki/Microsoft_.NET" class="mw-redirect" title="Microsoft .NET">.NET</a> и, следовательно, использует все новые возможности, предоставляемые этой платформой.
</p>

<div class="mw-heading mw-heading2"><h2 id="История_ASP.NET"><span id=".D0.98.D1.81.D1.82.D0.BE.D1.80.D0.B8.D1.8F_ASP.NET"></span>История ASP.NET</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=ASP.NET&amp;veaction=edit&amp;section=1" title="Редактировать раздел «История ASP.NET»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=ASP.NET&amp;action=edit&amp;section=1" title="Редактировать код раздела «История ASP.NET»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p>После выпуска сервера <a href="/wiki/Internet_Information_Services" title="Internet Information Services">Internet Information Services</a> 4.0 в 1997 году, компания <a href="/wiki/Microsoft" title="Microsoft">Microsoft</a> начала исследовать возможность новой модели веб-приложения, которая удовлетворит жалобы на ASP, особенно связанные с отделением оформления от содержания, и которая позволит писать «чистый» код<sup id="cite&#95;ref-architecturejournal&#95;3-0" class="reference"><a href="#cite_note-architecturejournal-3"><span class="cite-bracket">&#91;</span>3<span class="cite-bracket">&#93;</span></a></sup>. Работа по разработке такой модели была поручена Марку Андерсу, менеджеру команды IIS, и <a href="/wiki/%D0%93%D0%B0%D1%82%D1%80%D0%B8,_%D0%A1%D0%BA%D0%BE%D1%82%D1%82" title="Гатри, Скотт">Скотту Гатри</a>, поступившему на работу в <a href="/wiki/Microsoft" title="Microsoft">Microsoft</a> в 1997. Андерс и Гатри разработали первоначальный проект в течение двух месяцев, и Гатри написал код первоначального прототипа во время рождественских каникул 1997 года.<sup id="cite&#95;ref-otegem&#95;4-0" class="reference"><a href="#cite_note-otegem-4"><span class="cite-bracket">&#91;</span>4<span class="cite-bracket">&#93;</span></a></sup>
</p><p>Первоначальный проект назывался «XSP»; Гатри объяснил в интервью 2007 года, что «всегда спрашивают, что означает буква X. В то время она ничего не значила. <a href="/wiki/XML" title="XML">XML</a> начинается с неё; <a href="/wiki/XSLT" title="XSLT">XSLT</a> начинается с неё. Все клевое начинается с X, поэтому мы его так и назвали.»<sup id="cite&#95;ref-architecturejournal&#95;3-1" class="reference"><a href="#cite_note-architecturejournal-3"><span class="cite-bracket">&#91;</span>3<span class="cite-bracket">&#93;</span></a></sup> Прототип XSP был написан на <a href="/wiki/Java" title="Java">Java</a>, так как на тот момент у <a href="/wiki/Microsoft" title="Microsoft">Microsoft</a> не было Java-подобной технологии. В то время уже предполагалось (небезосновательно, как выяснилось в дальнейшем), что лицензирование <a href="/wiki/Java" title="Java">Java</a> для <a href="/wiki/Microsoft" title="Microsoft">Microsoft</a> не будет продлено в 2003 году (в 2003 истекал срок выданной <a href="/wiki/Sun_Microsystems" title="Sun Microsystems">Sun Microsystems</a> лицензии). В 1999 компанией <a href="/wiki/Microsoft" title="Microsoft">Майкрософт</a> было решено построить платформу с общеязыковой средой исполнения <a href="/wiki/Common_Language_Runtime" title="Common Language Runtime">Common Language Runtime</a> (CLR) и на её основе развить технологии. В ней, как и в <a href="/wiki/Java" title="Java">Java</a>, использовались <a href="/wiki/%D0%9F%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5" title="Программирование">программирование</a> по принципам <a href="/wiki/%D0%9E%D0%B1%D1%8A%D0%B5%D0%BA%D1%82%D0%BD%D0%BE-%D0%BE%D1%80%D0%B8%D0%B5%D0%BD%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%BD%D0%BE%D0%B5_%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5" title="Объектно-ориентированное программирование">ООП</a>, <a href="/wiki/%D0%A1%D0%B1%D0%BE%D1%80%D0%BA%D0%B0_%D0%BC%D1%83%D1%81%D0%BE%D1%80%D0%B0_(%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5)" class="mw-redirect" title="Сборка мусора (программирование)">сборка мусора</a> и другие возможности<sup id="cite&#95;ref-anderselreg&#95;5-0" class="reference"><a href="#cite_note-anderselreg-5"><span class="cite-bracket">&#91;</span>5<span class="cite-bracket">&#93;</span></a></sup>. Гатри описал это решение как «огромный риск», так как успех новой разработки был связан с успехом CLR, которая, как и XSP, находилась на ранней стадии разработки.
</p>
<div class="mw-heading mw-heading2"><h2 id="Принципы_ASP.NET"><span id=".D0.9F.D1.80.D0.B8.D0.BD.D1.86.D0.B8.D0.BF.D1.8B_ASP.NET"></span>Принципы ASP.NET</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=ASP.NET&amp;veaction=edit&amp;section=2" title="Редактировать раздел «Принципы ASP.NET»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=ASP.NET&amp;action=edit&amp;section=2" title="Редактировать код раздела «Принципы ASP.NET»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p>Поскольку ASP.NET основывается на <a href="/wiki/Common_Language_Runtime" title="Common Language Runtime">Common Language Runtime</a> (CLR), которая является основой всех приложений Microsoft .NET, разработчики могут писать код для ASP.NET, используя <a href="/wiki/%D0%AF%D0%B7%D1%8B%D0%BA_%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F" title="Язык программирования">языки программирования</a>, входящие в комплект <a href="/wiki/.NET_Framework" title=".NET Framework">.NET Framework</a> (<a href="/wiki/C_Sharp" title="C Sharp">C#</a>, <a href="/wiki/VB.NET" class="mw-redirect" title="VB.NET">Visual Basic.NET</a>, J# и <a href="/wiki/JScript_.NET" class="mw-redirect" title="JScript .NET">JScript .NET</a>)<sup id="cite&#95;ref-:0&#95;1-1" class="reference"><a href="#cite_note-:0-1"><span class="cite-bracket">&#91;</span>1<span class="cite-bracket">&#93;</span></a></sup>.
</p><p>Программная модель ASP.NET основывается на протоколе <a href="/wiki/HTTP" title="HTTP">HTTP</a> и использует его правила взаимодействия между сервером и браузером. При формировании страницы заложена абстрактная программная модель Web Forms и на ней основана основная часть реализации программного кода<sup id="cite&#95;ref-:0&#95;1-2" class="reference"><a href="#cite_note-:0-1"><span class="cite-bracket">&#91;</span>1<span class="cite-bracket">&#93;</span></a></sup>.В целом, ASP.NET предлагает множество преимуществ для разработки веб-приложений, включая мощные инструменты, высокую производительность и богатый набор библиотек.
</p>
<div class="mw-heading mw-heading2"><h2 id="Программные_модели"><span id=".D0.9F.D1.80.D0.BE.D0.B3.D1.80.D0.B0.D0.BC.D0.BC.D0.BD.D1.8B.D0.B5_.D0.BC.D0.BE.D0.B4.D0.B5.D0.BB.D0.B8"></span>Программные модели</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=ASP.NET&amp;veaction=edit&amp;section=3" title="Редактировать раздел «Программные модели»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=ASP.NET&amp;action=edit&amp;section=3" title="Редактировать код раздела «Программные модели»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p>В ASP.NET поддерживается несколько программных моделей для создания веб-приложений<sup id="cite&#95;ref-6" class="reference"><a href="#cite_note-6"><span class="cite-bracket">&#91;</span>6<span class="cite-bracket">&#93;</span></a></sup>:
</p>
<ul><li><span data-interwiki-lang="en" data-interwiki-article="ASP.NET Web Forms"><a href="/w/index.php?title=ASP.NET_Web_Forms&amp;action=edit&amp;redlink=1" class="new" title="ASP.NET Web Forms (страница отсутствует)">ASP.NET Web Forms</a></span><sup class="noprint" style="font-style:normal; font-weight:normal;"><a href="https://en.wikipedia.org/wiki/ASP.NET_Web_Forms" class="extiw" title="en:ASP.NET Web Forms"><span title="ASP.NET Web Forms — версия статьи «ASP.NET Web Forms» на английском языке">[англ.]</span></a></sup>&#160;— <a href="/wiki/%D0%A4%D1%80%D0%B5%D0%B9%D0%BC%D0%B2%D0%BE%D1%80%D0%BA" title="Фреймворк">фреймворк</a> для создания модульных <a href="/wiki/%D0%92%D0%B5%D0%B1-%D1%81%D1%82%D1%80%D0%B0%D0%BD%D0%B8%D1%86%D0%B0" title="Веб-страница">веб-страниц</a> из компонентов с обработкой событий <a href="/wiki/%D0%98%D0%BD%D1%82%D0%B5%D1%80%D1%84%D0%B5%D0%B9%D1%81_%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D0%B5%D0%BB%D1%8F" title="Интерфейс пользователя">пользовательского интерфейса</a> на стороне сервера;</li>
<li><a href="/wiki/ASP.NET_MVC_Framework" title="ASP.NET MVC Framework">ASP.NET MVC</a>&#160;— фреймворк для создания веб-страниц с использованием шаблона проектирования <a href="/wiki/Model-View-Controller" title="Model-View-Controller">MVC</a>;</li>
<li><span data-interwiki-lang="en" data-interwiki-article="ASP.NET Web Pages"><a href="/w/index.php?title=ASP.NET_Web_Pages&amp;action=edit&amp;redlink=1" class="new" title="ASP.NET Web Pages (страница отсутствует)">ASP.NET Web Pages</a></span><sup class="noprint" style="font-style:normal; font-weight:normal;"><a href="https://en.wikipedia.org/wiki/ASP.NET_Web_Pages" class="extiw" title="en:ASP.NET Web Pages"><span title="ASP.NET Web Pages — версия статьи «ASP.NET Web Pages» на английском языке">[англ.]</span></a></sup>&#160;— упрощённый <a href="/wiki/%D0%A1%D0%B8%D0%BD%D1%82%D0%B0%D0%BA%D1%81%D0%B8%D1%81" title="Синтаксис">синтаксис</a> для добавления динамического кода и доступа к данным внутри <a href="/wiki/HTML" title="HTML">HTML</a> разметки веб-страниц<sup id="cite&#95;ref-7" class="reference"><a href="#cite_note-7"><span class="cite-bracket">&#91;</span>7<span class="cite-bracket">&#93;</span></a></sup>;</li>
<li>ASP.NET <a href="/wiki/API" title="API">Web API</a>&#160;— фреймворк для создания <a href="/w/index.php?title=Web_API&amp;action=edit&amp;redlink=1" class="new" title="Web API (страница отсутствует)">Web API</a> поверх <a href="/wiki/.NET_Framework" title=".NET Framework">.NET Framework</a><sup id="cite&#95;ref-8" class="reference"><a href="#cite_note-8"><span class="cite-bracket">&#91;</span>8<span class="cite-bracket">&#93;</span></a></sup>;</li>
<li>ASP.NET WebHooks&#160;— реализация шаблона <a href="/wiki/Webhook" title="Webhook">Webhook</a> для подписки на события и публикации событий через HTTP;</li>
<li><span data-interwiki-lang="en" data-interwiki-article="SignalR"><a href="/w/index.php?title=SignalR&amp;action=edit&amp;redlink=1" class="new" title="SignalR (страница отсутствует)">SignalR</a></span><sup class="noprint" style="font-style:normal; font-weight:normal;"><a href="https://en.wikipedia.org/wiki/SignalR" class="extiw" title="en:SignalR"><span title="SignalR — версия статьи «SignalR» на английском языке">[англ.]</span></a></sup>&#160;— фреймворк для двунаправленного обмена сообщениями в реальном времени между клиентом и сервером.</li></ul>
<p>Другие расширения ASP.NET:
</p>
<ul><li><span data-interwiki-lang="en" data-interwiki-article="HTTP handler"><a href="/w/index.php?title=HTTP_handler&amp;action=edit&amp;redlink=1" class="new" title="HTTP handler (страница отсутствует)">ASP.NET Handler</a></span><sup class="noprint" style="font-style:normal; font-weight:normal;"><a href="https://en.wikipedia.org/wiki/HTTP_handler" class="extiw" title="en:HTTP handler"><span title="HTTP handler — версия статьи «HTTP handler» на английском языке">[англ.]</span></a></sup>&#160;— компоненты, реализующие интерфейс <code>System.Web.IHttpHandler</code>. В отличие от страниц ASP.NET у них нет файла с HTML разметкой, нет поддержки обработки событий и других вспомогательных технологий. Они содержат только файл с программным кодом, написанным на любом из <a href="/wiki/%D0%A1%D0%BF%D0%B8%D1%81%D0%BE%D0%BA_.NET-%D1%8F%D0%B7%D1%8B%D0%BA%D0%BE%D0%B2" title="Список .NET-языков">.NET-совместимых языков</a>, который записывает какие-то данные в HTTP ответ. HTTP обработчики схожи с <a href="/wiki/ISAPI" title="ISAPI">ISAPI</a>-расширениями;</li>
<li><a href="/wiki/ASP.NET_AJAX" title="ASP.NET AJAX">ASP.NET AJAX</a>&#160;— расширение, содержащее как клиентские, так и серверные компоненты для создания ASP.NET страниц, реализующих <a href="/wiki/AJAX" title="AJAX">AJAX</a> функциональность;</li>
<li><span data-interwiki-lang="en" data-interwiki-article="ASP.NET Dynamic Data"><a href="/w/index.php?title=ASP.NET_Dynamic_Data&amp;action=edit&amp;redlink=1" class="new" title="ASP.NET Dynamic Data (страница отсутствует)">ASP.NET Dynamic Data</a></span><sup class="noprint" style="font-style:normal; font-weight:normal;"><a href="https://en.wikipedia.org/wiki/ASP.NET_Dynamic_Data" class="extiw" title="en:ASP.NET Dynamic Data"><span title="ASP.NET Dynamic Data — версия статьи «ASP.NET Dynamic Data» на английском языке">[англ.]</span></a></sup>&#160;— <a href="/wiki/%D0%A1%D0%BA%D0%B0%D1%84%D1%84%D0%BE%D0%BB%D0%B4%D0%B8%D0%BD%D0%B3" title="Скаффолдинг">скаффолдинговое</a> расширение для создания управляемых данными приложений.</li></ul>
<div class="mw-heading mw-heading2"><h2 id="Безопасность"><span id=".D0.91.D0.B5.D0.B7.D0.BE.D0.BF.D0.B0.D1.81.D0.BD.D0.BE.D1.81.D1.82.D1.8C"></span>Безопасность</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=ASP.NET&amp;veaction=edit&amp;section=4" title="Редактировать раздел «Безопасность»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=ASP.NET&amp;action=edit&amp;section=4" title="Редактировать код раздела «Безопасность»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p>В ASP.NET, для управления системой <a href="/wiki/%D0%90%D1%83%D1%82%D0%B5%D0%BD%D1%82%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%86%D0%B8%D1%8F" title="Аутентификация">аутентификации</a> пользователей на сайте, был реализован за счет Membership API, который представляет средства для входа, хранения и управления учетными записями пользователей. Архитектура Membership API выстроена таким образом, что позволяет управлять пользователями хранящимся в различных источниках: <a href="/wiki/Microsoft_SQL_Server" title="Microsoft SQL Server">Microsoft SQL Server</a>, <a href="/wiki/Active_Directory" title="Active Directory">Microsoft Active Directory</a> или специальное хранилище (реализованное самим, но тогда необходимо самому реализовывать поставщик, чтобы подключиться к обобщенной базе поставщиков)<sup id="cite&#95;ref-:1&#95;9-0" class="reference"><a href="#cite_note-:1-9"><span class="cite-bracket">&#91;</span>9<span class="cite-bracket">&#93;</span></a></sup><sup id="cite&#95;ref-10" class="reference"><a href="#cite_note-10"><span class="cite-bracket">&#91;</span>10<span class="cite-bracket">&#93;</span></a></sup>. В ASP.NET <a href="/wiki/%D0%90%D1%83%D1%82%D0%B5%D0%BD%D1%82%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%86%D0%B8%D1%8F" title="Аутентификация">аутентификация</a> может осуществляется с помощью форм, либо с помощью <a href="/wiki/Windows" title="Windows">Windows</a> через <a href="/wiki/Internet_Information_Services" title="Internet Information Services">IIS</a><sup id="cite&#95;ref-:1&#95;9-1" class="reference"><a href="#cite_note-:1-9"><span class="cite-bracket">&#91;</span>9<span class="cite-bracket">&#93;</span></a></sup><sup id="cite&#95;ref-11" class="reference"><a href="#cite_note-11"><span class="cite-bracket">&#91;</span>11<span class="cite-bracket">&#93;</span></a></sup>. Безопасность: ASP.NET предоставляет набор средств для обеспечения безопасности приложений, включая встроенные механизмы защиты от атак, таких как SQL-инъекции и кросс-сайтового  скриптинга .
</p>
<div class="mw-heading mw-heading2"><h2 id="Преимущества_ASP.NET_перед_ASP"><span id=".D0.9F.D1.80.D0.B5.D0.B8.D0.BC.D1.83.D1.89.D0.B5.D1.81.D1.82.D0.B2.D0.B0_ASP.NET_.D0.BF.D0.B5.D1.80.D0.B5.D0.B4_ASP"></span>Преимущества ASP.NET перед ASP</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=ASP.NET&amp;veaction=edit&amp;section=5" title="Редактировать раздел «Преимущества ASP.NET перед ASP»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=ASP.NET&amp;action=edit&amp;section=5" title="Редактировать код раздела «Преимущества ASP.NET перед ASP»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<ul><li>Компилируемый код выполняется быстрее, большинство ошибок отлавливается ещё на стадии разработки;</li>
<li>Значительно улучшенная обработка ошибок во время выполнения запущенной готовой программы, с использованием блоков try..catch;</li>
<li>Пользовательские элементы управления (controls) позволяют выделять часто используемые шаблоны, такие как меню сайта;</li>
<li>Использование метафор, уже применяющихся в Windows-приложениях, например, таких как элементы управления и события;</li>
<li>Расширяемый набор элементов управления и библиотек классов позволяет быстрее разрабатывать приложения;</li>
<li>ASP.NET опирается на многоязыковые возможности <a href="/wiki/.NET_Framework" title=".NET Framework">.NET</a>, что позволяет писать код страниц на <a href="/wiki/Visual_Basic_.NET" title="Visual Basic .NET">VB.NET</a>, <a href="/wiki/Delphi_(%D1%8F%D0%B7%D1%8B%D0%BA_%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F)" title="Delphi (язык программирования)">Delphi.NET</a>, <a href="/wiki/C_Sharp" title="C Sharp">Visual C#</a>, <a href="/wiki/Visual_J_Sharp" title="Visual J Sharp">J#</a> и&#160;т.&#160;д.;</li>
<li>Возможность кэширования всей страницы или её части для увеличения производительности;</li>
<li>Возможность кэширования данных, используемых на странице;</li>
<li>Возможность разделения визуальной части и <a href="/wiki/%D0%91%D0%B8%D0%B7%D0%BD%D0%B5%D1%81-%D0%BB%D0%BE%D0%B3%D0%B8%D0%BA%D0%B0" title="Бизнес-логика">бизнес-логики</a> по разным файлам («code behind»);</li>
<li>Расширяемая модель обработки запросов;</li>
<li>Расширенная событийная модель;</li>
<li>Расширяемая модель серверных элементов управления;</li>
<li>Наличие master-страниц для задания шаблонов оформления страниц;</li>
<li>Поддержка <a href="/wiki/CRUD" title="CRUD">CRUD</a>-операций при работе с таблицами через GridView;</li>
<li>Встроенная поддержка <a href="/wiki/AJAX" title="AJAX">AJAX</a>;</li></ul>
