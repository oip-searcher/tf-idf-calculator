<p><b>Степь</b>&#160;— <a href="/wiki/%D0%A0%D0%B0%D0%B2%D0%BD%D0%B8%D0%BD%D0%B0" title="Равнина">равнина</a>, поросшая <a href="/wiki/%D0%A2%D1%80%D0%B0%D0%B2%D1%8F%D0%BD%D0%B8%D1%81%D1%82%D1%8B%D0%B5_%D1%80%D0%B0%D1%81%D1%82%D0%B5%D0%BD%D0%B8%D1%8F" title="Травянистые растения">травянистой растительностью</a>, в <a href="/wiki/%D0%A3%D0%BC%D0%B5%D1%80%D0%B5%D0%BD%D0%BD%D1%8B%D0%B9_%D0%BA%D0%BB%D0%B8%D0%BC%D0%B0%D1%82" title="Умеренный климат">умеренных</a> и <a href="/wiki/%D0%A1%D1%83%D0%B1%D1%82%D1%80%D0%BE%D0%BF%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D0%B9_%D0%BF%D0%BE%D1%8F%D1%81" class="mw-redirect" title="Субтропический пояс">субтропических зонах</a> <a href="/wiki/%D0%A1%D0%B5%D0%B2%D0%B5%D1%80%D0%BD%D0%BE%D0%B5_%D0%BF%D0%BE%D0%BB%D1%83%D1%88%D0%B0%D1%80%D0%B8%D0%B5" title="Северное полушарие">Северного</a> и <a href="/wiki/%D0%AE%D0%B6%D0%BD%D0%BE%D0%B5_%D0%BF%D0%BE%D0%BB%D1%83%D1%88%D0%B0%D1%80%D0%B8%D0%B5" title="Южное полушарие">Южного полушарий</a>. Характерной особенностью степей является отсутствие или очень малое количество <a href="/wiki/%D0%94%D0%B5%D1%80%D0%B5%D0%B2%D0%BE" title="Дерево">деревьев</a> (не считая искусственных насаждений и лесополос вдоль водоёмов и путей сообщения).
</p>

<div class="mw-heading mw-heading2"><h2 id="Этимология"><span id=".D0.AD.D1.82.D0.B8.D0.BC.D0.BE.D0.BB.D0.BE.D0.B3.D0.B8.D1.8F"></span>Этимология</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%D0%A1%D1%82%D0%B5%D0%BF%D1%8C&amp;veaction=edit&amp;section=1" title="Редактировать раздел «Этимология»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=%D0%A1%D1%82%D0%B5%D0%BF%D1%8C&amp;action=edit&amp;section=1" title="Редактировать код раздела «Этимология»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p>У слова «степь» нет общепринятой этимологии<sup id="cite&#95;ref-Vasmer&#95;1-0" class="reference"><a href="#cite_note-Vasmer-1"><span class="cite-bracket">&#91;</span>1<span class="cite-bracket">&#93;</span></a></sup>.
</p><p>Одна из версий говорит о <a href="/wiki/%D0%A2%D1%8E%D1%80%D0%BA%D0%B8" title="Тюрки">тюркском</a> происхождении слова «степь», так как слово «иситеп» с <a href="/wiki/%D0%A2%D1%8E%D1%80%D0%BA%D1%81%D0%BA%D0%B8%D0%B5_%D1%8F%D0%B7%D1%8B%D0%BA%D0%B8" title="Тюркские языки">тюркского языка</a> означает «согревать, согревший»<sup id="cite&#95;ref-2" class="reference"><a href="#cite_note-2"><span class="cite-bracket">&#91;</span>2<span class="cite-bracket">&#93;</span></a></sup>. Согласно некоторым письменным источникам, таким как «<a href="/wiki/%D0%9F%D0%BE%D0%B2%D0%B5%D1%81%D1%82%D1%8C_%D0%B2%D1%80%D0%B5%D0%BC%D0%B5%D0%BD%D0%BD%D1%8B%D1%85_%D0%BB%D0%B5%D1%82" title="Повесть временных лет">Повесть временных лет</a>», именно <a href="/wiki/%D0%A2%D1%8E%D1%80%D0%BA%D0%B8" title="Тюрки">тюрков</a> называли степняками, <a href="/wiki/%D0%9C%D0%BE%D0%BD%D0%B3%D0%BE%D0%BB%D1%8C%D1%81%D0%BA%D0%B0%D1%8F_%D0%B8%D0%BC%D0%BF%D0%B5%D1%80%D0%B8%D1%8F" title="Монгольская империя">Монгольскую империю</a> — степной империей, а территорию <a href="/wiki/%D0%9F%D0%BE%D0%BB%D0%BE%D0%B2%D1%86%D1%8B" title="Половцы">половцев</a> — <a href="/wiki/%D0%94%D0%B5%D1%88%D1%82-%D0%B8-%D0%9A%D0%B8%D0%BF%D1%87%D0%B0%D0%BA" title="Дешт-и-Кипчак">Половецкой степью</a> или полем, что может свидетельствовать, что со «степным народом» с древности<sup class="ts-fix-template">&#91;<i><a href="/wiki/%D0%92%D0%B8%D0%BA%D0%B8%D0%BF%D0%B5%D0%B4%D0%B8%D1%8F:%D0%9F%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D1%8F%D0%B5%D0%BC%D0%BE%D1%81%D1%82%D1%8C#Бремя_доказательства" title="Википедия:Проверяемость"><span title="информация нуждается в подтверждении авторитетными источниками">уточнить</span></a></i>&#93;</sup> отождествляли тюрков<sup id="cite&#95;ref-3" class="reference"><a href="#cite_note-3"><span class="cite-bracket">&#91;</span>3<span class="cite-bracket">&#93;</span></a></sup>.
</p><p>Если оно произошло от <a href="/wiki/%D0%94%D1%80%D0%B5%D0%B2%D0%BD%D0%B5%D1%80%D1%83%D1%81%D1%81%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA" title="Древнерусский язык">древнерусской</a> формы <span style="font-style:normal;"><span lang="orv" class="script-slavonic" style="font-size: 110%; font-family: Menaion, Monomakh, &#39;Ponomar Unicode&#39;, Ponomar, Fedorovsk, Noto Sans Gothic, Segoe UI Historic, BukyVede, &#39;Kliment Std&#39;, &#39;RomanCyrillic Std&#39;, &#39;Hirmos Ponomar&#39;, Dilyana, Menaion, &#39;Menaion Medieval&#39;, Lazov, Code2000, &#39;DejaVu Sans&#39;, &#39;DejaVu Serif&#39;, Code2001, FreeSans, FreeSerif, &#39;TITUS Cyberbit Basic&#39;, &#39;Charis SIL&#39;, &#39;Doulos SIL&#39;, &#39;Chrysanthi Unicode&#39;, &#39;Bitstream Cyberbit&#39;, &#39;Bitstream CyberBase&#39;, Thryomanes, &#39;Lucida Grande&#39;, &#39;Arial Unicode MS&#39;, &#39;Microsoft Sans Serif&#39;, &#39;Lucida Sans Unicode&#39;, &#39;Noto Sans&#39;;">*стьпь</span></span>, то дальнейшее происхождение неясно; <a href="/wiki/%D0%A4%D0%B0%D1%81%D0%BC%D0%B5%D1%80,_%D0%9C%D0%B0%D0%BA%D1%81" title="Фасмер, Макс">Фасмер</a> считает недостоверным сравнение с <a href="/wiki/%D0%9B%D0%B8%D1%82%D0%BE%D0%B2%D1%81%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA" title="Литовский язык">лит.</a> <span lang="lt" style="font-style:italic;">stiẽpti</span> «простираться», <a href="/wiki/%D0%9B%D0%B0%D1%82%D1%8B%D1%88%D1%81%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA" title="Латышский язык">латыш.</a> <span lang="lv" style="font-style:italic;">stiept</span> «тянуть»<sup id="cite&#95;ref-Vasmer&#95;1-1" class="reference"><a href="#cite_note-Vasmer-1"><span class="cite-bracket">&#91;</span>1<span class="cite-bracket">&#93;</span></a></sup>. Если древней формой было <span style="font-style:normal;"><span lang="orv" class="script-slavonic" style="font-size: 110%; font-family: Menaion, Monomakh, &#39;Ponomar Unicode&#39;, Ponomar, Fedorovsk, Noto Sans Gothic, Segoe UI Historic, BukyVede, &#39;Kliment Std&#39;, &#39;RomanCyrillic Std&#39;, &#39;Hirmos Ponomar&#39;, Dilyana, Menaion, &#39;Menaion Medieval&#39;, Lazov, Code2000, &#39;DejaVu Sans&#39;, &#39;DejaVu Serif&#39;, Code2001, FreeSans, FreeSerif, &#39;TITUS Cyberbit Basic&#39;, &#39;Charis SIL&#39;, &#39;Doulos SIL&#39;, &#39;Chrysanthi Unicode&#39;, &#39;Bitstream Cyberbit&#39;, &#39;Bitstream CyberBase&#39;, Thryomanes, &#39;Lucida Grande&#39;, &#39;Arial Unicode MS&#39;, &#39;Microsoft Sans Serif&#39;, &#39;Lucida Sans Unicode&#39;, &#39;Noto Sans&#39;;">*сътепь</span></span> (от того же славянского корня, как «топот», «топтать»), то в <a href="/wiki/%D0%A3%D0%BA%D1%80%D0%B0%D0%B8%D0%BD%D1%81%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA" title="Украинский язык">украинском языке</a> следовало бы ожидать не <span lang="uk" style="font-style:italic;">степ</span>, а <span lang="uk" style="font-style:italic;">*стіп</span>; с другой стороны, возможно, что в украинский язык слово попало из русского, а не древнерусского<sup id="cite&#95;ref-Vasmer&#95;1-2" class="reference"><a href="#cite_note-Vasmer-1"><span class="cite-bracket">&#91;</span>1<span class="cite-bracket">&#93;</span></a></sup>. Возможно и происхождение от формы <span style="font-style:normal;"><span lang="orv" class="script-slavonic" style="font-size: 110%; font-family: Menaion, Monomakh, &#39;Ponomar Unicode&#39;, Ponomar, Fedorovsk, Noto Sans Gothic, Segoe UI Historic, BukyVede, &#39;Kliment Std&#39;, &#39;RomanCyrillic Std&#39;, &#39;Hirmos Ponomar&#39;, Dilyana, Menaion, &#39;Menaion Medieval&#39;, Lazov, Code2000, &#39;DejaVu Sans&#39;, &#39;DejaVu Serif&#39;, Code2001, FreeSans, FreeSerif, &#39;TITUS Cyberbit Basic&#39;, &#39;Charis SIL&#39;, &#39;Doulos SIL&#39;, &#39;Chrysanthi Unicode&#39;, &#39;Bitstream Cyberbit&#39;, &#39;Bitstream CyberBase&#39;, Thryomanes, &#39;Lucida Grande&#39;, &#39;Arial Unicode MS&#39;, &#39;Microsoft Sans Serif&#39;, &#39;Lucida Sans Unicode&#39;, &#39;Noto Sans&#39;;">*сътеп</span></span> («вырубленное место»; ср. старинный глагол тепти&#160;— «рубить»)<sup id="cite&#95;ref-Vasmer&#95;1-3" class="reference"><a href="#cite_note-Vasmer-1"><span class="cite-bracket">&#91;</span>1<span class="cite-bracket">&#93;</span></a></sup><sup id="cite&#95;ref-4" class="reference"><a href="#cite_note-4"><span class="cite-bracket">&#91;</span>4<span class="cite-bracket">&#93;</span></a></sup>.
</p><p>Из <a href="/wiki/%D0%A0%D1%83%D1%81%D1%81%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA" title="Русский язык">русского языка</a> слово попало в западноевропейские&#160;— <a href="/wiki/%D0%9D%D0%B5%D0%BC%D0%B5%D1%86%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA" title="Немецкий язык">немецкий</a>, <a href="/wiki/%D0%A4%D1%80%D0%B0%D0%BD%D1%86%D1%83%D0%B7%D1%81%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA" title="Французский язык">французский</a>, <a href="/wiki/%D0%90%D0%BD%D0%B3%D0%BB%D0%B8%D0%B9%D1%81%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA" title="Английский язык">английский</a>, причём заимствование произошло уже в XVI&#160;в.&#160;— <a href="/wiki/%D0%90%D0%BD%D0%B3%D0%BB%D0%B8%D0%B9%D1%81%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA" title="Английский язык">англ.</a>&#160;<span lang="en" style="font-style:italic;">steppe</span> встречается в лексиконе <a href="/wiki/%D0%A8%D0%B5%D0%BA%D1%81%D0%BF%D0%B8%D1%80,_%D0%A3%D0%B8%D0%BB%D1%8C%D1%8F%D0%BC" title="Шекспир, Уильям">Шекспира</a><sup id="cite&#95;ref-Vasmer&#95;1-4" class="reference"><a href="#cite_note-Vasmer-1"><span class="cite-bracket">&#91;</span>1<span class="cite-bracket">&#93;</span></a></sup><sup id="cite&#95;ref-5" class="reference"><a href="#cite_note-5"><span class="cite-bracket">&#91;</span>5<span class="cite-bracket">&#93;</span></a></sup>.
</p>
<div class="mw-heading mw-heading2"><h2 id="Растительный_мир"><span id=".D0.A0.D0.B0.D1.81.D1.82.D0.B8.D1.82.D0.B5.D0.BB.D1.8C.D0.BD.D1.8B.D0.B9_.D0.BC.D0.B8.D1.80"></span>Растительный мир</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%D0%A1%D1%82%D0%B5%D0%BF%D1%8C&amp;veaction=edit&amp;section=2" title="Редактировать раздел «Растительный мир»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=%D0%A1%D1%82%D0%B5%D0%BF%D1%8C&amp;action=edit&amp;section=2" title="Редактировать код раздела «Растительный мир»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<div role="note" class="hatnote navigation-not-searchable ts-main">Основная статья: <a href="/wiki/%D0%A1%D1%82%D0%B5%D0%BF%D0%BD%D1%8B%D0%B5_%D1%80%D0%B0%D1%81%D1%82%D0%B5%D0%BD%D0%B8%D1%8F" title="Степные растения">Степные растения</a></div>
<p>Характерная черта степи&#160;— преимущественно безлесное пространство, покрытое травянистой растительностью. Травы, образующие сомкнутый или почти сомкнутый ковёр: <a href="/wiki/%D0%9A%D0%BE%D0%B2%D1%8B%D0%BB%D1%8C" title="Ковыль">ковыль</a>, <a href="/wiki/%D0%A2%D0%B8%D0%BF%D1%87%D0%B0%D0%BA" title="Типчак">типчак</a>, <a href="/wiki/%D0%A2%D0%BE%D0%BD%D0%BA%D0%BE%D0%BD%D0%BE%D0%B3" title="Тонконог">тонконог</a>, <a href="/wiki/%D0%9C%D1%8F%D1%82%D0%BB%D0%B8%D0%BA" title="Мятлик">мятлик</a>, <a href="/wiki/%D0%9E%D0%B2%D1%81%D0%B5%D1%86" title="Овсец">овсец</a>, <a href="/wiki/%D0%A1%D0%BE%D0%BB%D1%8F%D0%BD%D0%BA%D0%B0_(%D1%80%D0%B0%D1%81%D1%82%D0%B5%D0%BD%D0%B8%D0%B5)" title="Солянка (растение)">солянка</a>, <a href="/wiki/%D0%9B%D0%B0%D0%B1%D0%B0%D0%B7%D0%BD%D0%B8%D0%BA" class="mw-redirect" title="Лабазник">лабазник</a>, перекати-поле и др. Растения приспосабливаются к неблагоприятным условиям. Многие из них засухоустойчивы либо активны весной, когда ещё остаётся влага после зимы.
</p>

<div class="mw-heading mw-heading2"><h2 id="Типы_степей"><span id=".D0.A2.D0.B8.D0.BF.D1.8B_.D1.81.D1.82.D0.B5.D0.BF.D0.B5.D0.B9"></span>Типы степей</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%D0%A1%D1%82%D0%B5%D0%BF%D1%8C&amp;veaction=edit&amp;section=3" title="Редактировать раздел «Типы степей»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=%D0%A1%D1%82%D0%B5%D0%BF%D1%8C&amp;action=edit&amp;section=3" title="Редактировать код раздела «Типы степей»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p><span class="ts-fix-text" style="-webkit-box-decoration-break: clone">В зависимости от растительности и режима увлажнения степи подразделяют на пять основных подвидов:
</span></p>
<ul><li>горные (криоксерофильные)<sup id="cite&#95;ref-6" class="reference"><a href="#cite_note-6"><span class="cite-bracket">&#91;</span>6<span class="cite-bracket">&#93;</span></a></sup>;</li>
<li>луговые или разнотравные (мезоксерофильные) степи;</li>
<li>настоящие (<a href="/wiki/%D0%9A%D1%81%D0%B5%D1%80%D0%BE%D1%84%D0%B8%D1%82%D1%8B" title="Ксерофиты">ксерофитные</a>) с преобладанием многолетних <a href="/wiki/%D0%94%D1%91%D1%80%D0%BD" class="mw-redirect" title="Дёрн">дерновинных</a> злаков, главным образом <a href="/wiki/%D0%9A%D0%BE%D0%B2%D1%8B%D0%BB%D1%8C" title="Ковыль">ковыля</a>&#160;— так называемые ковыльные степи;</li>
<li>сазовые (галоксерофильные)&#160;— степи, состоящие из растений, у которых надземные органы несут черты приспособления к засушливому климату, но произрастают при наличии постоянного или временного грунтового увлажнения;</li>
<li>пустынные (суперксерофильные) степи с участием пустынных трав и полукустарников <a href="/wiki/%D0%9F%D0%BE%D0%BB%D1%8B%D0%BD%D1%8C" title="Полынь">полыни</a> и <a href="/wiki/%D0%92%D0%B8%D1%82%D0%B5%D0%BA%D1%81" class="mw-redirect" title="Витекс">прутняка</a>, а также <a href="/wiki/%D0%AD%D1%84%D0%B5%D0%BC%D0%B5%D1%80%D1%8B" title="Эфемеры">эфемеров и эфемероидов</a>.<sup class="ts-fix-template noprint">&#91;<i><a href="/wiki/%D0%92%D0%B8%D0%BA%D0%B8%D0%BF%D0%B5%D0%B4%D0%B8%D1%8F:%D0%A1%D1%81%D1%8B%D0%BB%D0%BA%D0%B8_%D0%BD%D0%B0_%D0%B8%D1%81%D1%82%D0%BE%D1%87%D0%BD%D0%B8%D0%BA%D0%B8" title="Википедия:Ссылки на источники"><span title="не указан источник на утверждение (29 ноября 2017)">источник не указан 3037 дней</span></a></i>&#93;</sup></li></ul>
<p>Фрагменты отдельных типов степей имеются в <a href="/wiki/%D0%9B%D0%B5%D1%81%D0%BE%D1%81%D1%82%D0%B5%D0%BF%D1%8C" title="Лесостепь">лесостепи</a> и в <a href="/wiki/%D0%9F%D0%BE%D0%BB%D1%83%D0%BF%D1%83%D1%81%D1%82%D1%8B%D0%BD%D1%8F" title="Полупустыня">полупустыне</a>.
</p><p>На разных континентах степь имеет разные названия: в Северной Америке&#160;— <a href="/wiki/%D0%9F%D1%80%D0%B5%D1%80%D0%B8%D1%8F" title="Прерия">прерии</a>; в Южной Америке&#160;— <a href="/wiki/%D0%9F%D0%B0%D0%BC%D0%BF%D0%B0%D1%81%D1%8B" class="mw-redirect" title="Пампасы">пампа, или пампасы</a>, а в тропиках&#160;— <a href="/wiki/%D0%9B%D1%8C%D1%8F%D0%BD%D0%BE%D1%81" title="Льянос">льянос</a>. Аналогом южноамериканских льянос в Африке и в Австралии является <a href="/wiki/%D0%A1%D0%B0%D0%B2%D0%B0%D0%BD%D0%BD%D0%B0" title="Саванна">саванна</a>. В Новой Зеландии степь называется <a href="/wiki/%D0%A2%D1%83%D1%81%D1%81%D0%BE%D0%BA%D0%B8" title="Туссоки">туссоки</a>.
</p>
<div class="mw-heading mw-heading2"><h2 id="Животный_мир"><span id=".D0.96.D0.B8.D0.B2.D0.BE.D1.82.D0.BD.D1.8B.D0.B9_.D0.BC.D0.B8.D1.80"></span>Животный мир</h2><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%D0%A1%D1%82%D0%B5%D0%BF%D1%8C&amp;veaction=edit&amp;section=4" title="Редактировать раздел «Животный мир»" class="mw-editsection-visualeditor"><span>править</span></a><span class="mw-editsection-divider"> | </span><a href="/w/index.php?title=%D0%A1%D1%82%D0%B5%D0%BF%D1%8C&amp;action=edit&amp;section=4" title="Редактировать код раздела «Животный мир»"><span>править код</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p>Как по видовому составу, так и по некоторым экологическим особенностям животный мир степи имеет много общего с животным миром пустыни. Как и пустыня, степь характеризуется высокой засушливостью. Зимой в степи часто бывают сильные холода, и обитающим в ней животным и растениям приходится приспосабливаться, помимо высоких, ещё и к низким температурам. Животные активны летом преимущественно ночью. Из копытных типичны виды, отличающиеся острым зрением и способностями к быстрому и длительному бегу, например, <a href="/wiki/%D0%90%D0%BD%D1%82%D0%B8%D0%BB%D0%BE%D0%BF%D1%8B" title="Антилопы">антилопы</a>; из грызунов&#160;— строящие сложные норы <a href="/wiki/%D0%A1%D1%83%D1%81%D0%BB%D0%B8%D0%BA%D0%B8" title="Суслики">суслики</a>, <a href="/wiki/%D0%A1%D1%83%D1%80%D0%BA%D0%B8" title="Сурки">сурки</a>, <a href="/wiki/%D0%A1%D0%BB%D0%B5%D0%BF%D1%8B%D1%88%D0%B8" class="mw-redirect" title="Слепыши">слепыши</a> и прыгающие виды: <a href="/wiki/%D0%A2%D1%83%D1%88%D0%BA%D0%B0%D0%BD%D1%87%D0%B8%D0%BA%D0%B8" class="mw-redirect" title="Тушканчики">тушканчики</a>, <a href="/wiki/%D0%9A%D0%B5%D0%BD%D0%B3%D1%83%D1%80%D0%BE%D0%B2%D1%8B%D0%B5_%D0%BF%D1%80%D1%8B%D0%B3%D1%83%D0%BD%D1%8B" title="Кенгуровые прыгуны">кенгуровые крысы</a>.
</p><p>Большая часть птиц на зиму улетает. Обычные пернатые обитатели степей&#160;— это <a href="/wiki/Aquila_nipalensis" class="mw-redirect" title="Aquila nipalensis">степной орёл</a>, <a href="/wiki/%D0%94%D1%80%D0%BE%D1%84%D0%B0" title="Дрофа">дрофа</a>, <a href="/wiki/%D0%A1%D1%82%D0%B5%D0%BF%D0%BD%D0%BE%D0%B9_%D0%BB%D1%83%D0%BD%D1%8C" title="Степной лунь">степной лунь</a>, <a href="/wiki/%D0%A1%D1%82%D0%B5%D0%BF%D0%BD%D0%B0%D1%8F_%D0%BF%D1%83%D1%81%D1%82%D0%B5%D0%BB%D1%8C%D0%B3%D0%B0" title="Степная пустельга">степная пустельга</a>, <a href="/wiki/%D0%96%D0%B0%D0%B2%D0%BE%D1%80%D0%BE%D0%BD%D0%BA%D0%BE%D0%B2%D1%8B%D0%B5" title="Жаворонковые">жаворонки</a>. Многочисленны <a href="/wiki/%D0%9F%D1%80%D0%B5%D1%81%D0%BC%D1%8B%D0%BA%D0%B0%D1%8E%D1%89%D0%B8%D0%B5%D1%81%D1%8F" title="Пресмыкающиеся">пресмыкающиеся</a> и <a href="/wiki/%D0%9D%D0%B0%D1%81%D0%B5%D0%BA%D0%BE%D0%BC%D1%8B%D0%B5" title="Насекомые">насекомые</a>. <a href="/wiki/%D0%AF%D1%89%D0%B5%D1%80%D0%B8%D1%86%D1%8B" title="Ящерицы">Ящерицы</a> (например, <a href="/wiki/%D0%92%D0%B0%D1%80%D0%B0%D0%BD" class="mw-redirect" title="Варан">вараны</a>) могут во время засухи довольно долго жить без воды.
</p>
